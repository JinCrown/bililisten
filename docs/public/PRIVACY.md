# 隐私与本地数据

这是当前 Android 版本的实现说明，不是哔哩哔哩的隐私政策。

- 本项目没有自建账号服务器；搜索、推荐、播放、账号和消息等请求连接到
  哔哩哔哩及相关内容分发服务。平台可以获得请求所必需的信息。
- 手动查找歌词时会向 LRCLIB（lrclib.net）发送输入的歌名、歌手或搜索词，
  获取歌词时会发送候选记录编号。该服务使用独立客户端，不附带 B站凭据。
- 登录会话保存在设备上，应用使用它访问当前账号有权限的内容。登录后
  请把手机和应用的数据导出文件当作私人数据保管。
- 收听历史正常在本地保存。“实时同步B站最近记录”默认关闭；开启后会
  向平台提交播放记录。关闭该选项不代表登录、播放等其他请求完全离线。
- 收藏、点赞、投币等账号操作需要相应的用户操作，并会发送给平台。
  私信和通知目前用于查看，不提供自动发消息功能。
- 缓存、下载、设置、本地历史和导入导出文件可能包含个人收听信息。
  数据转移功能应只在自己信任的设备和网络中使用。
- 本项目源码中没有面向作者的统计上报或广告 SDK；第三方平台仍有自己的
  服务规则和数据处理方式，第三方修改版也不能由本项目保证。
- 应用禁用 Android 系统自动备份。仍应注意主动导出、系统调试和截图的
  信息泄露风险；卸载或清理数据前请自行备份希望保留的本地数据。

公开仓库不包含作者的登录会话、签名私钥、设备实测日志或账号截图。
